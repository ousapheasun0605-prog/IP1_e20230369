# Milestone Checklist and Design Answers

## M0 — Proposal

### Design Question

**Which story did you cut from the MVP, and why?**

I decided to exclude the ingredient autocomplete feature from the initial MVP. As a member, I would like to receive ingredient suggestions while entering recipe ingredients, so that recipe creation becomes more convenient. However, implementing this feature requires maintaining a list of common ingredients and developing additional suggestion logic. Since members can already enter ingredient names manually, this feature is not essential to the main purpose of the application. It may be considered for a future version if time allows.
